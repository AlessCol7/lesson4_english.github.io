Chapter 02 // The Grand Architecture

The Conditionals Reality Spectrum: Which One Do I Pick?

English speakers don't pick a conditional because of grammar rules in a textbook. They pick a conditional based on two fundamental questions:

1. What is the Probability?

• 100% Guaranteed = Type 0 (Universal Law)
• 50% Plausible / Likely = Type 1 (Real Plan)
• 1% Fantasy / Unreal = Type 2 (Daydream)
• 0% Impossible = Type 3 (Past History)

2. What is the Timeframe?

• Timeless / Any Time = Type 0
• Future / Upcoming = Type 1
• Right Now (Hypothetical) = Type 2
• Already Finished Yesterday = Type 3

The All-in-One Multiverse Comparison Matrix

Conditional Probability Timeframe Formula Blueprint Real-World Example
Type 0 100% (Certain) Timeless / Always If + Present Simple, ... Present Simple If you overclock a CPU without cooling, it overheats.
Type 1 50% (Real chance) Tomorrow / Future If + Present Simple, ... will / can + V1 If we practice tonight, we will win our match on Saturday.
Type 2 1% (Unreal / Dream) Right Now / Future If + Past Simple (V2), ... would + V1 If I had an RTX 4090 right now, I would stream in 4K.
Type 3 0% (Impossible) Finished Past If + had + V3, ... would have + V3 If we had installed the patch on Friday, the game wouldn't have crashed.

Chapter 04 // The Multiverse Deep Dive

Mastering Conditionals 2 & 3: Nuance, Mindset & Contrasts

Contrast Duel #1: Type 1 vs. Type 2 (Confidence vs. Fantasy)

Compare these two sentences. Both talk about the future, but they mean completely different things:

• Type 1: "If I get 100% on my English exam next week, my father will buy me the new headset."
➔ Speaker's Mindset: I studied hard. This is very possible and realistic!
• Type 2: "If I got a million dollars tomorrow, I would build an esports stadium in Bucharest."
➔ Speaker's Mindset: A total daydream. Fun to imagine, but almost zero probability.

Conditional 2: The Hypothetical Present / Dream

When do you use it?

  • Daydreaming about your current life: "If I had more free time after school, I would learn game design." (Reality: You have too much homework right now).
  • Giving Advice: "If I were you, I would talk to the coach about your role." (Notice: In formal English, we use were instead of was for all persons: If I were, if he were).
  • Imagining alternate physics or science fiction: "If humans could fly, we would not need airports."

Formula: If + Past Simple (V2), ... would / could / might + V1

Contrast Duel #2: Type 2 vs. Type 3 (Present Dream vs. Past Regret)

This is where many students hesitate. Notice the timeline difference:

• Type 2 (Talking about NOW): "If I spoke fluent Japanese right now, I would translate this game."
➔ Situation is occurring currently in the present.
• Type 3 (Talking about YESTERDAY): "If I had studied for yesterday's test, I would have passed."
➔ The test is over. Time has moved forward. You cannot change what happened!

Conditional 3: The Time Machine (Alternative History)

When do you use it?

  • Post-Match Debriefs (Esports & Sports): "If our sniper had hit that shot in Round 15, we would have qualified for the finals."
  • Regrets & Excuses: "If my alarm had gone off at 07:00, I would not have been late for school."
  • Historical "What Ifs": "If the Roman Empire had not collapsed, European history would have looked completely different."

Formula: If + had + V3 (Past Perfect), ... would have + V3

The Spider Anchor Law: Irregular Verb Precision

Theo, when writing essays, past stories, or Conditional 3 sentences, remember this core rule:

⚡ V2 (Simple Past) SWINGS ALONE: It never has a helper verb next to it.
"Our community grew by 50% last winter." (Never say: "was grew" or "has grew").

🕸️ V3 (Past Participle) MUST HAVE A WEB-LINE HELPER (have / has / had / is / was / been):
"If our studio had grown..." / "The game was built in Unreal Engine."
